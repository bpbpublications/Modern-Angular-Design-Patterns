Chapter 7 — State Management with NgRx

Store, actions, reducers, effects, selectors, and the facade pattern — the NgRx demos below share one live 'cart' feature slice (registered via this chapter's routes), so dispatching in one card updates every card: a single source of truth.


This page registers the very same providers for real via chapter-07.routes.ts (route-level provideStore, provideStoreDevtools, provideEffects), which powers every NgRx demo on this page. With the Redux DevTools browser extension installed you can watch each dispatched action and state change.
