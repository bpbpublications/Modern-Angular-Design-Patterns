Chapter 8 — Routing with Angular Standalone APIs

Route configuration, dynamic parameters, functional guards and resolvers, complex routing scenarios, and the Router lifecycle. The book's route arrays are mounted for real in a routed playground at /chapter-08/router-demo.


  • Organize routes by lazy loaded features (feature.routes.ts + loadChildren) — identical to complex-routing/admin.routes.ts.
  • Use route guards to enforce access control; combine them for layered security.
  • Apply lowercase, hyphenated, readable paths.
  • Handle wildcard fallbacks last: { path: '**', redirectTo: '/not-found' }.
  • Minimize deeply nested routes (2–3 levels).
  • Avoid hardcoding paths: <a [routerLink]="['/products', product.id]">View</a>.
  • Use query parameters for filters/sorts; listen to router events for UX enhancements.
