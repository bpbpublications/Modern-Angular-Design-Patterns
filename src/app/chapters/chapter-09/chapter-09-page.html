Chapter 9 — Lazy Loading and Performance Optimization

The lazy pattern, feature-based lazy loading with standalone components, preloading strategies, NgOptimizedImage, CLI build optimization, and feature flags. The book's lazy route arrays are mounted for real at /chapter-09/lazy-demo.


  • ng build --configuration=production — AOT, tree shaking, minification.
  • ng build --configuration=production --stats-json — generate a build report.
  • npx webpack-bundle-analyzer dist/your-app/stats.json — analyze the bundle (legacy webpack builder; the modern esbuild builder has its own analyze tooling).
  • Split code on demand: loadChildren: () => import('./admin/admin.routes').then(m => m.ADMIN_ROUTES) — mounted live in the lazy playground.
  • Prefer targeted imports (e.g. lodash/debounce), standalone components, and server-side Gzip/Brotli compression.
