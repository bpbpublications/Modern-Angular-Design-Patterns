Chapter 13 — Micro-Frontends with Angular Elements

Splitting a frontend into independently developed and deployed units: Angular Elements as framework-agnostic web components, singleton services for shared state, and dynamic dependency injection across isolated runtimes. The custom elements below are registered for real inside this app.


  • Independent deployment — ship parts of the UI without touching the rest.
  • Technology agnostic — mix frameworks or Angular versions per slice.
  • Team autonomy — cross-functional teams own features end to end.
  • Scalability & maintainability — smaller, focused, testable codebases.
